EDIBREW WEBSITE - UPLOAD GUIDE
==============================
Upload EVERYTHING in this folder to the ROOT of your GitHub repository (keep your existing "assets" folder).

PAGES (HTML)
index, cups, spoons, why, customers, bulk, checkout, contact   (existing, upgraded)
faq, track, reviews, thankyou, shipping, refund, privacy, terms, food-safety, 404   (new)

SUPPORT FILES
buyer-email-setup.txt + emailjs-template.html = optional branded confirmation email to the buyer (EmailJS, free)
config.js  = YOUR SETTINGS. Edit this one file for hours, social links, payment accounts, coupons, stock, reviews, analytics.
site.js, site.css = shared code and styles (no need to edit)
sitemap.xml, robots.txt = for Google
google-sheets-orders.gs = optional order log in Google Sheets (instructions inside the file)

DO THESE AFTER UPLOADING
1. Done: your site address (https://shahzadfaran05-jpg.github.io/Edibrew./) is already set in all files.
2. Place one test order. FormSubmit emails an activation link to muhammadfaranshahzad@gmail.com. Click it once, or order emails will not arrive.
3. Set up the buyer confirmation email: follow buyer-email-setup.txt (10 minutes).
4. Open config.js and fill in: real support hours, Instagram/Facebook/TikTok links, JazzCash/Easypaisa/bank details if you accept them.
5. Check the policy pages (refund, shipping, food safety, terms, privacy) and edit any rule that is not true for your business.
6. Submit sitemap.xml in Google Search Console.
